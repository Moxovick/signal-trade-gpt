name: UI Improvement Plan
description: Ongoing UI/UX redesign priorities for web platform and Telegram bot
type: project
---

User wants a more polished, readable, and pleasant interface across:
- Website (landing, dashboard, settings, signals, admin)
- Telegram bot (both regular bot and Mini App)

**Settings pages** — user specifically flagged as "пиздец какие хуёвые". Key issues: flat layout, no visual hierarchy, boring sidebar, plain forms.

**Why:** Settings is a high-touch area; bad UX here loses trust.
**How to apply:** Prioritize settings redesign. Add visual groups in sidebar, better active states, more structured page headers, richer stat displays.

**Dashboard & signals** — signal feed is a dense table, not readable. TopNav uses outdated underline tabs.

**Bot** — needs full rework to be beautiful and functional as both regular bot and Mini App.
